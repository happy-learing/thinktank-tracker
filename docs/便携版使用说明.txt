智库研究追踪 便携版

运行
1. 将完整 ZIP 解压到本机可写目录，不要直接在压缩包或 U 盘内运行。
2. 双击“启动智库追踪.exe”。程序只监听 127.0.0.1，并自动打开浏览器。
3. 首次进入“环境诊断”，再到“智库来源”导入 Word 或 sources.json。
4. API 密钥须在每台电脑分别填写，密钥仅保存到 Windows Credential Manager。
5. 默认已配置 DeepSeek 官方地址和 deepseek-v4-flash；在“设置”填写 API 密钥后点击“保存并测试连接”。

来源与检索入口
- 来源按“配置1、配置2……”完全独立保存；先在来源页选择配置，再管理该配置自己的智库和入口。
- 可新增空配置、复制当前配置、重命名或移入回收站。复制配置会复制全部来源和发现规则，但不会复制历史任务、最近成功日期或链接测试结果。
- 新建任务必须选择一个配置；程序记住最近成功创建任务时使用的配置，并在下次明确显示为默认选项。
- 一个智库可以添加多个检索入口，任务按智库汇总、按入口分别记录覆盖状态。
- 程序只从给定入口及其分页发现文章；详情页可以在同站其他路径，但不会从详情页继续采集相关文章。
- 用户提供的入口不会被程序替换成内置默认栏目。
- 体裁只从 URL 独立路径段或栏目卡片 DOM 的完整标签识别；隐藏或悬停标签也可读取。两类证据冲突、未知标签或均未命中时转人工。可在“设置 > 体裁规则”维护匹配方式、匹配值、规范体裁和处理方式。
- 程序已经运行时，再次双击“启动智库追踪.exe”会复用当前服务并重新打开浏览器标签页，无需从历史记录进入。
- 来源和入口可以直接启用、停用；配置、智库和入口删除后进入回收站，历史任务不受影响。
- 每个入口可预览首个栏目页的接收/拒绝结果，并可配置卡片选择器、日期选择器、允许路径和排除路径。
- 每个智库的“测试链接”会测试当前配置中该智库的全部启用入口；必要时回退 Chromium，但只检查首个栏目页，不创建任务、不调用模型。

日期范围与内容清单
- 指定日期范围内的全部正式栏目内容都会展示，即使体裁、篇幅或主题不符合要求。
- 日期待确认内容单独显示；本次边界扫描遇到的过新、过旧内容默认折叠，且不下载 PDF、不调用主题模型。
- 按日期排序入口越过起始日后，只再验证 10 条新发现且日期已确认的过旧内容；日期不明、置顶重复和日期逆序不计入。

人工复核
- 候选按任务分组，每页 20 个任务组；默认展开最新匹配任务，也可同时展开多个任务。
- 顶部状态筛选作用于所有任务，展开后只加载该任务符合筛选条件的候选，不再受全局 500 条限制。
- 日期缺失或冲突时，填写发布日期并勾选“已核对原文发布日期”。
- 批准纳入时必须同时填写确认日期、主分类、英文标题、中文标题、作者、深度研究体裁和一句话核心观点；作者输入框每行一位，体裁可选择“自定义”。
- 自动主题初筛只在日期、体裁、篇幅和正文提取通过后执行一次；证据必须能在正文逐字回查。点击“生成字段建议”不会重新进行主题判断。建议只填入当前表单，不会确认日期、保存审核或自动批准。
- PDF 附件会单独审计；默认由本地 AnyDoc 生成结构化 Markdown，失败或正文过短时回退 pypdf，不会调用托管 OCR。设置页可切换为“兼容模式（仅 pypdf）”。
- 可信主 PDF 的正文比 HTML 更完整时，程序使用 PDF 正文并保留网页日期、标题和体裁证据；OCR 页面、实际解析器、耗时和回退原因会进入人工复核页与 Excel“PDF附件”表。

任务与回收站
- 已结束任务可以移入回收站；运行中或排队中的任务不能删除。
- 回收站中的入口和任务可以恢复。永久清除必须输入 DELETE，且程序会先创建数据库备份。
- 设置页可执行一次性“备份并清空历史”，保留来源、入口、模型配置和 Windows 凭据。

目录
- app：程序运行时，只读。
- runtime：与 Playwright 版本匹配的 Chromium headless shell，只读。
- workspace：数据库、配置、日志、缓存、导出和备份，可写。

迁移到另一台电脑
- 复制完整解压目录可以复制程序。
- `sources.json` schema v5 可导出当前配置或全部配置，并保存卡片容器、体裁标签选择器和统一体裁规则；仅复制该文件可以复用来源和规则，不会复制历史。

- 正式 Word 按智库分组，仅包含人工批准文章，条目为作者、英中标题、英文日期和独立 URL。无符合项与覆盖说明只进入审计 XLSX；批准项缺少作者、双语标题或确认日期时整次 Word 导出失败。
- 两台电脑独立使用时，不要互相覆盖 workspace。
- 需要故障恢复时，在程序关闭后恢复数据库备份。

升级
1. 先在旧版本“设置”中创建数据库备份，然后关闭程序。
2. 解压新版到新目录。
3. 将旧版 workspace 整体复制到新版根目录，确认目标程序未运行。
4. 启动新版；数据库迁移会自动执行，并先在 workspace/backups 创建迁移前数据库备份。不要用新版 workspace 覆盖回旧版。

完整性
- 右键使用 PowerShell 运行“验证完整性.ps1”。
- SHA256SUMS.txt 覆盖发布包内所有文件，不包含其自身。
- THIRD_PARTY_NOTICES.txt 包含 AnyDoc 的 MIT 许可证文本。
